# 🚀 Telegram Network Monitor Bot (Serverless)

یک ربات تلگرام حرفه‌ای و سبک برای پایش وضعیت شبکه، تست پینگ جهانی و تهیه اسکرین‌شات از سایت‌ها که بر بستر **Cloudflare Workers** اجرا می‌شود.

## ✨ قابلیت‌ها
- ⚡ **Global Ping:** تست پینگ از ۴ نقطه جهان از جمله ایران (IR).
- 📸 **Web Screenshot:** تهیه اسکرین‌شات زنده از سایت‌های مقصد.
- ℹ️ **IP Info:** نمایش جزئیات کامل شبکه، اپراتور و موقعیت مکانی.
- 🌐 **HTTP Test:** بررسی کد وضعیت پاسخدهی سرور (Status Code).
- 🛡 **Security:** دسترسی کاملاً محدود شده به ادمین.

## 🛠 پیش‌نیازها
برای راه‌اندازی به موارد زیر نیاز دارید:
1. توکن ربات تلگرام از [BotFather](https://t.me/botfather).
2. کلید API از سایت [ApiFlash](https://apiflash.com) (برای اسکرین‌شات).
3. یک حساب رایگان [Cloudflare](https://cloudflare.com).

## 🚀 راهنمای نصب
1. این مخزن را در گیت‌هاب خود کپی (Fork) کنید.
2. در پنل کلودفلر یک **Worker** جدید بسازید.
3. در بخش **Settings > Variables**، متغیرهای زیر را اضافه کنید:
   - `BOT_TOKEN`: توکن تلگرام شما.
   - `ADMIN_ID`: آی‌دی عددی تلگرام شما.
   - `API_FLASH_KEY`: کلید سایت ApiFlash.
4. بخش **Build & Deployment** را به این ریپازیتوری متصل کنید.
5. وب‌هوک تلگرام خود را با آدرس ورکر ست کنید:
   `https://api.telegram.org/bot<TOKEN>/setWebhook?url=<WORKER_URL>`

## 📊 سرویس‌های مورد استفاده
- **Globalping API:** برای تست‌های شبکه جهانی.
- **ip-api:** برای استعلام جزئیات آی‌پی.
- **ApiFlash:** برای تبدیل آدرس وب به تصویر.
