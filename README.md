# 🌐 Telegram Network Monitor Bot (Serverless)

یک ربات تلگرامی قدرتمند، سبک و کاملاً رایگان (بدون نیاز به سرور) برای پایش شبکه‌های کامپیوتری، تست پینگ جهانی و دریافت اطلاعات دقیق از IP و دامنه‌ها. این ربات بر بستر **Cloudflare Workers** اجرا می‌شود و مدیریت آن به صورت مستقیم از طریق **GitHub** انجام می‌گیرد.

---

## ✨ قابلیت‌های کلیدی

* **⚡ پینگ جهانی (Global Ping):** تست زنده وضعیت شبکه از ۷ نقطه مختلف جهان (ایران 🇮🇷، آلمان 🇩🇪، آمریکا 🇺🇸، هلند 🇳🇱، انگلیس 🇬🇧، ترکیه 🇹🇷 و روسیه 🇷🇺).
* **🌐 تست پاسخدهی HTTP:** بررسی کد وضعیت (Status Code) سایت‌ها از سرورهای جهانی.
* **📸 گزارش تصویری (Screenshot):** تهیه اسکرین‌شات خودکار از صفحه آنالیز `Check-Host` برای دامنه یا IP مورد نظر با کیفیت بالا.
* **🔍 آنالیز دقیق IP:** استخراج اطلاعات کامل شامل کشور، شهر، اپراتور (ISP)، نام سازمان (Org) و شماره AS.
* **🛡 امنیت بالا:** دسترسی به ربات کاملاً شخصی‌سازی شده و فقط برای ادمین (بر اساس Telegram User ID) امکان‌پذیر است.

---

## 🛠 پیش‌نیازها

قبل از راه‌اندازی، به موارد زیر نیاز دارید:
1. **توکن ربات تلگرام:** از [BotFather](https://t.me/botfather) دریافت کنید.
2. **آی‌دی عددی تلگرام (Admin ID):** شناسه عددی اکانت تلگرام خودتان (برای محدود کردن دسترسی).
3. **حساب رایگان Cloudflare:** برای اجرای کدهای ربات (Workers).
4. **کلید API سرویس ScreenshotLayer:** یک حساب رایگان در [ScreenshotLayer](https://screenshotlayer.com) بسازید و Access Key خود را کپی کنید.

## 🚀 راهنمای نصب و راه‌اندازی (استقرار خودکار)

این پروژه از سیستم **Git Integration** کلودفلر استفاده می‌کند، بنابراین هر تغییری در گیت‌هاب بلافاصله روی ربات شما اعمال می‌شود.

### مرحله اول: آماده‌سازی گیت‌هاب
1. یک ریپازیتوری (ترجیحاً Private) در حساب GitHub خود بسازید.
2. فایل‌های `worker.js` (کدهای اصلی ربات) و `wrangler.toml` (تنظیمات کلودفلر) را در آن قرار دهید و فایل‌ها را Commit کنید.

### مرحله دوم: اتصال به کلودفلر
1. وارد پنل کاربری **Cloudflare** شوید و به بخش **Workers & Pages** بروید.
2. روی دکمه **Create Application** و سپس **Create Worker** کلیک کنید.
3. نام Worker خود را وارد کرده و آن را Deploy کنید.
4. وارد تنظیمات Worker شده، به تب **Settings** و سپس بخش **Build & Deployment** بروید.
5. در قسمت **Git repository**، روی **Connect to Git** کلیک کرده و مخزن گیت‌هابی که ساختید را انتخاب کنید.

### مرحله سوم: تنظیم متغیرهای محیطی (Secrets)
در پنل کلودفلر، به مسیر **Settings > Variables and Secrets** بروید و روی **Add** کلیک کنید تا متغیرهای زیر را به صورت **Secret** ذخیره کنید:

| نام متغیر | توضیحات |
| :--- | :--- |
| `BOT_TOKEN` | توکن ربات تلگرام شما (مثال: `123456:ABC-DEF1234...`) |
| `ADMIN_ID` | آی‌دی عددی تلگرام شما (مثال: `123456789`) |
| `API_FLASH_KEY` | کلید دسترسی (Access Key) دریافتی از سایت *ScreenshotLayer* |

*نکته: پس از ذخیره این متغیرها، یک‌بار دیگر در کلودفلر دکمه Deploy را بزنید تا تنظیمات جدید اعمال شود.*

### مرحله چهارم: تنظیم Webhook تلگرام
برای اینکه تلگرام پیام‌ها را به ربات شما بفرستد، باید آدرس Worker خود را به تلگرام معرفی کنید.
آدرس زیر را در مرورگر خود کپی کرده، مقادیر `<TOKEN>` و `<WORKER_URL>` را با اطلاعات خود جایگزین کنید و دکمه Enter را بزنید:
`text
[https://api.telegram.org/bot](https://api.telegram.org/bot)<TOKEN>/setWebhook?url=<WORKER_URL>`


(مثال Worker URL: https://my-bot.username.workers.dev)

اگر با پیغام {"ok":true,"result":true,"description":"Webhook was set"} مواجه شدید، ربات شما با موفقیت متصل شده است!
